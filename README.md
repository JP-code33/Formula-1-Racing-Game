# Formula-1-Racing-Game

I have made a Formula 1 style 2D racing game built with **Python** and **Pygame**. You race against a computer controlled car, progress through easy levels to difficult ones. You can pick the car you want and pick the opponent car and try to beat the computer!

# Features
1. Formula 1 style racing game
2. Computer opponent which chooses the best racing line!
3. Choose your own Formula 1 car and your opponent's car
4. Formula 1 style starting lights
5. Pause Menu
6. Settings Menu
7. How to Play Menu
8. Turn On/Off sound effects
9. Volume slider
10. Hover animations

# Installation

You can install this game right on your computer. You just simply have to go over to the Release section in this repository and download the main.exe file as it is the official executable file for the app. If you download this and your computer tells you this is by an unknown publisher then click more info and click run anyway. This happens because the app is not registered. Then you can just have fun playing it!
